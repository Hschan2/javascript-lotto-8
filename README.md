## 구현 일기
### 요구사항에만 집중해 시작부터 코드를 복잡하게 작성했다
요구사항에만 집중해서 이해도가 아직 낮고, 제대로 활용할 수 없는 구문들을 사용하려고 하다 보니 오히려 코드가 복잡해졌다. 그래서 스스로 작성한 코드임에도 코드나 파일의 양이 하나씩 많아질수록 이해하기 어려웠다. 그래서 처음부터 다시 시작해 모든 기능들을 한 번에 구현하고, 테스트를 통과하고 나서 코드들을 분리하기 시작했다. 조금씩 각 기능에 따라 맞는 위치에 이동시키고, 메소드를 분리하는 과정을 거치니 전보다 이해하기 쉬웠고, 요구사항도 최대한 맞출 수 있었던 것 같다.   
   
-> 그러나 아직 개선할 점이 많다.

### 공통 피드백과 다른 사람들의 코드를 읽어보니 개선점이 보였다
공통 피드백과 전 미션들의 다른 사람들이 작성한 코드들을 읽어보니 내가 개선해야 할 점들이 보였다. 예를 들어, 상수 처리를 하여 여러 메소드에서 중복 사용하는 것들을 하드 코딩하지 않고, 하나의 변수에 담아 값이 변하더라도 한 번만 수정하여 재사용할 수 있도록 만들 수 있었다.   

그러나, 아직 이해하지 못한 부분에 대해서는 그냥 가져와서 적용하는 것은 피했습니다. 단순히 미션을 통과하려고 그냥 가져와서 사용하기 보다 제대로 이해해야 사용하는 게 더 의미있다고 생각해 스스로 이해했다고 생각한 부분만 적용하고 그 외에 내용들은 이해할 때까지 학습하고, 생각하고, 고민하고 있습니다.   

특히, 메소드가 한 가지 일만 하도록 하는 요구사항에 있어서 지금 메소드가 한 가지 일만 하고 있는지에 대해 조금 더 이해와 고민이 필요해 아직까지 시간이 더 필요하다고 느끼고 있습니다.
