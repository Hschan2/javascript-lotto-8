# 세 번째 과제 - [로또] 기능구현 목록

## 입력 처리 (Console.readLineAsync())
- [ ] 당첨 번호와 보너스 번호 입력
    - [ ] 당첨 번호는 쉼표(,) 기준으로 구분

## 로또 발매 (입력 처리, Random.pickUniqueNumbersInRange())
- [ ] 1~45까지의 중복되지 않은 1개의 로또 발행
- [ ] 중복되지 않은 당첨번호 숫자 6개와 보너스 번호 1개 발행
    - [ ] 로또 구매 금액만큼 로또 당첨번호 발행
- [ ] 로또 가격 입력 (1장 당 1,000원)

## 로또 계산
- [ ] 1등 (6개 번호 일치) - 2,000,000,000원
- [ ] 2등 (5개 번호 + 보너스 번호 일치) - 30,000,000원
- [ ] 3등 (5개 번호 일치) - 1,500,000원
- [ ] 4등 (4개 번호 일치) - 50,000원
- [ ] 5등 (3개 번호 일치) - 5,000원

## 예외 처리
- [ ] 로또 번호
    - [ ] 1부터 45 사이의 숫자여야 함
    - [ ] 중복되지 않아야 함
- [ ] 보너스 번호
    - [ ] 보너스 번호는 1~45 사이의 한 개의 숫자가 중복되지 않아야 함
- [ ] 빈 문자열
    - [ ] 스페이스를 포함한 빈 문자열이 없어야 함
- [ ] 로또 구매
    - [ ] 1,000원 단위의 입력을 받아야 하며, 1,000원으로 나누어져야 함

## 출력 처리 (Console.print())
- [ ] 발행한 로또 수량 및 로또 번호를 오름차순으로 정렬하여 출력
- [ ] (사용자가 구매한 로또 번호와 당첨 번호를 비교) 당첨 내역 및 수익률 출력 (소수점 둘 째 자리에서 반올림)
